# 客户分级速查

唯一评分定义见[评分框架](client_scoring_framework.md)。不能在120分上额外加奖励分，也不使用另一个A/B/C等级覆盖T1–T4。

| 核查 | 规则 |
|---|---|
| 各维度上限 | 意向25、主体20、潜力20、匹配20、沟通15、社媒10、采购10 |
| 已知分 | S；每个已知分都要有来源和理由 |
| 已知上限 | K；只加有分数维度的上限 |
| 未知 | null，不填0，不推算满分 |
| 分数区间 | [S, S+120-K] |
| 覆盖率 | K/120 |
| 确定分级 | 覆盖率≥75%且整个区间落在同一等级 |
| 层级 | T1 90–120；T2 60–89；T3 30–59；T4 0–29 |
| 独立风险 | 身份、账号变更、付款/合同/合规疑点另列，高分不豁免 |

不要把免费邮箱、低粉丝、简短英语、单次样品或未搜索到记录直接视为低价值。输出应带一个可执行下一步，而不是只给分数。

计算：`python3 scripts/trade_tools.py score <file.json>`。输入文件不自动保存进仓库。
