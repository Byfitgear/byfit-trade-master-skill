## 联动逻辑

1. 搜索开发：确定产品、目标市场和供应链角色，找到候选主体。
2. 研究：核验主体，汇总市场、社媒、采购证据。
3. 判断：区分需求事实、痛点假设、客户优先级与交易风险。
4. 回复：选择邮件组当前阶段，用一项相关发现连接到可兑现价值。
5. 跟进：以客户反馈和可用证据更新计划，不自动发送或修改记录。

## 发现到回复的映射

| 调查发现 | 不宜直接声称 | 可以执行 |
|---|---|---|
| 官网新增产品类别 | 一定准备换供应商 | 询问新品类的规格和供应计划 |
| 招聘采购岗位 | 一定有采购预算 | 核查岗位职责，确认联系人是否负责该品类 |
| 新开门店公告 | 所有门店统一采购 | 询问总部/加盟商采购权限与开业时间 |
| 海关有历史同品类记录 | 正在采购或采购额等于记录金额 | 核对时期、进口人、品类与当前项目 |
| 买家抱怨安装成本 | 只要更低FOB价 | 拆分材料、运输、安装与维护成本 |
| 多次问材料检测 | 已确定要下单 | 发送相关型号范围的现有证据，确认验收门槛 |

## Email Group通用状态

`首次接触 → 澄清/报价 → 证据补充 → 异议协商 → 样品/PI/下单 → 维护`

沉默、拒绝、延期和投诉是分支，不是必须继续往下一封发。回复后重新判断阶段；明确退订或拒绝触达时停止开发。
