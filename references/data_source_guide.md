# 数据源、能力与限制

目录：官方企业/市场来源；交易记录；社媒；银行；检索选择；证据边界。

核查日期2026-11-02。以下URL是来源入口，不代表已有订阅、能访问全部数据或已核查某客户。

## 官方企业与市场来源

| 来源 | 用途 | 关键限制 |
|---|---|---|
| [UN Comtrade](https://comtradeplus.un.org/) / [来源说明](https://uncomtrade.org/docs/what-are-the-data-sources-for-un-comtrade/) | 国家/产品贸易结构、需求线索 | 官方统计口径和时期须核对；不提供某买家全部采购 |
| [WTO贸易与关税平台](https://ttd.wto.org/en) | 官方关税/进口数据入口 | 税率适用仍需产品分类、原产地与日期 |
| [英国Companies House](https://find-and-update.company-information.service.gov.uk/) | 英国登记主体、备案和文件 | 登记/备案不是经营质量或付款能力保证 |
| [GLEIF LEI查询说明](https://www.gleif.org/en/lei-data/lei-search/about-lei-search/how-to-use-lei-search) | 法律实体名称、地址和可用关系资料 | 无LEI不等于不合法；不是全体企业的信用评分库 |
| 目标国官方企业登记、证券监管/交易所、法院、海关、主管机关 | 实体、公告、公开财报、诉讼或贸易规范 | 必须先确认官方域名、覆盖范围和记录状态 |

不把一个国家登记方式机械套用其他国家。私营企业可能无公开财报；不能凭员工数或网站样式估算营业额并称事实。

## 企业级贸易与信用资料

ImportGenius、Panjiva、外贸邦、ImportYeti、D&B及其他数据服务仅在当前可访问、获授权且覆盖目标地区/时期时使用。不要默认免费、不需要登录、记录完整或覆盖所有运输方式。

有授权数据时保留原始查询、时间窗、单位、运输角色与覆盖限制。付费墙仅有摘要时标为线索。信用报告需注明评级日期、报告对象与局限，不自动向第三方传递完整报告。

## 社媒

LinkedIn、Facebook、Instagram、YouTube、X、TikTok、Pinterest与相关区域商务平台：官网外链优先，再用品牌/域名/地区交叉验证。认证标志、粉丝数、用户名相似不是充分身份确认；只能看公开相关职业/商务资料。

## 银行与付款核查

| 来源 | 能做的事 | 不能据此证明 |
|---|---|---|
| [SWIFT BIC说明](https://www.swift.com/standards/data-standards/bic-business-identifier-code) | 了解机构标识及查询方向 | 某私人账号归属、余额、信用或交易安全 |
| 银行官网/当地监管机构名录 | 核对机构名称、执照或公开联系方式 | 代理邮件真实、受益人必然与合同一致 |
| 用户依法持有的付款文件、银行确认资料 | 对比主体、银行、收款信息与变更 | 单份截图是真实、资金已不可撤回到账 |
| [FBI IC3 BEC说明](https://www.ic3.gov/CrimeInfo/BEC) | 账号变更及邮件欺诈风险的核验原则 | 代替银行或执法判断 |

遇到账号变更或身份冲突时，用独立的已知渠道确认；不根据可疑邮件新提供的号码自证真实性。不要索取密码、OTP或查询私人银行余额。

## 选择与停止

明确本次待核查结论后选源，不为堆砌工具数量同时查询所有服务。优先一种原始来源，再用必要的独立佐证；低价值重复搜索应停止。发现无法访问、超出覆盖或身份不能匹配时保留未知，继续其他阶段。

用户给name/email/message已足以触发任务相关读取与草稿，但不授权购买报告、群发、联系银行、导出联系人或保存原始客户数据。
